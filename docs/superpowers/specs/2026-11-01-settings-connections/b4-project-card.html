A · Agents as rows

Each agent the project exposes is a row with Connect, or a quiet "Connected" once it is a connection. Easiest to scan when a project has several agents; long route names never wrap.

B · Agents as chips

Agents are pills: an ink pill with a check is connected, an outlined pill with "+" connects it in one click. Most compact and modern; wraps onto a second line when a project has many agents.

Both: the log opens in its own sheet from "…", not inline on the card. A failed start shows the red "!" and one line saying why, with Show log beside it.
