## 2026-11-21 (what Stop does to a Codex turn's running commands)

- **D-267 Stopping a Codex turn ends the commands that turn started. The adapter asks Codex for its experimental requests to do it, and commands an earlier turn left running are not touched.** Codex 0.166 answers `turn/interrupt` by ending the turn but leaves a command it was running alive as a background terminal; its own terminal client lists those with `/ps` and ends them with `/stop`. Stop in this app sent only the interrupt, so a stopped `sleep 60` ran on under the coordinator's `codex app-server` (found in the 2026-11-20 smoke test, `docs/verification/2026-11-21-stopping-a-codex-turn-ends-the-commands-it-started.md`).
  - **The rule.** The adapter records the command items each running turn starts (`item/started` with `commandExecution`, by native turn id) and drops them when the turn completes. `interrupt` takes the stopped turn's set before it sends `turn/interrupt` (Codex reports the turn completed right after answering, which would drop it), then calls `thread/backgroundTerminals/list` and `thread/backgroundTerminals/terminate` for each terminal whose `itemId` is one of them. A Codex that refuses either request leaves the stop as it was; the interrupt's answer is unchanged.
  - **Experimental requests.** The three background-terminal requests are marked experimental in Codex 0.166 and are refused without `capabilities.experimentalApi` (seen live: "requires experimentalApi capability"), so the handshake now asks for it. The writer's call: it may add experimental fields to what Codex sends, which the adapter's lenient decoding ignores; nothing else in the adapter changes. Reverting is one value in `CodexProtocol.initializeParams`.
  - **Not `clean`.** `thread/backgroundTerminals/clean` ends every background terminal of the thread, including one an earlier turn left running on purpose (a dev server); `terminate` ends one by id.
  - **Tests.** `CodexAppServerTests.stoppingATurnEndsTheCommandsItStarted` (an earlier "leave" turn's terminal is kept, the stopped turn's is ended), `stoppingATurnWithNoCommandListsNothing`, `theHandshakeAsksForExperimentalRequests`; `CodexEventsTests` now expects the flag on. `fake-codex.py` gains background terminals and reports a stopped command turn completed before it answers the interrupt.
