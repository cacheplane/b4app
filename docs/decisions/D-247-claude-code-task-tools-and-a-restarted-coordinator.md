## 2026-11-17 (Claude Code's task tools, and a coordinator started again)

- **D-247 The app asks Claude Code for its task tools, and a session started again finds its transcript without a history read first (amends D-243 and D-246).** The first live Claude Code check of D-243's row, on 2.1.282 through the installed Local build, found that the row could not appear and that the list was lost after a coordinator restart.
  - **The task tools.** Claude Code 2.1.282 gives a session run over stream-json no `TaskCreate` or `TaskUpdate` (and no `TodoWrite` at all) unless `CLAUDE_CODE_ENABLE_TODO_TOOLS` is set: asked for a task list, the model answered that it had no such tool. `ClaudeStream.childEnvironment` now sets it to `1`, since the app draws the list those tools keep; a value already in the environment stands, so the owner can turn it off. The variable is not documented: it was read from the CLI's own strings and confirmed by the tools `system/init` lists with and without it. If a later Claude Code drops or renames it, sessions lose the tools again and no row is drawn; nothing else breaks. Re-check on a CLI upgrade (`docs/compatibility.md`).
  - **A coordinator started again.** D-246 seeds a resumed session's list from its transcript under the projects folder Claude Code reports, which the adapter learns only from `ensureAccount`: a new session or a history read. A coordinator started again sends a turn on an existing session before either, so the seed read nothing, every `TaskUpdate` on an earlier task was dropped, and the turn drew no list until a reconcile imported one (a row with no turn). The resume now falls back to where Claude Code keeps transcripts by default (`ClaudeAdapter.projectsRoot`, as `deleteSession` already did), and `seededTasks` no longer takes an absent folder.
  - **Not changed.** The reconciled row that has no turn is what an import gives any item the live turn never wrote, and with the seed fixed the live turn writes it. The task tools arrive deferred, so a session's first use draws a `ToolSearch` tool row before the list; that row is Claude Code's own tool use and stays.
  - **Verification.** `docs/verification/2026-11-17-claude-code-task-tools-live.md`. The live check ran against the build without these fixes; the fixes are fixture-tested, and the variable was observed on the real CLI.
