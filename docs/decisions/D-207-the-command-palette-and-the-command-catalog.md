## 2026-11-11 (command palette)

- **D-207 One palette for Find and Commands, a typed command catalog behind it, and `/` in the composer (amends D-053, D-131, D-201).** The ⌘K thread search becomes a palette with two purposes, and the app's actions are declared once in a catalog that the palette, the Mac's File menu, the top bar, and the composer's `/` list all read. The owner's spec is the "B4 Agent Workspace Command Palette Specification" pasted on 2026-11-11; the mockups it was built to are the canvas "Command Palette Mockups".
  - **Catalog** (`Sources/WorkspaceUI/Palette/CommandCatalog.swift`). A `CommandID` is a stable string (`thread.pin`, `workspace.newThread`). A `CommandDefinition` carries its title, aliases, symbol, shortcut, `/` name, and what argument it needs (`none`, `choice`, `text`). A `CommandTarget` names what a command acts on by identity (`thread(id)`, `environment(id)`, `connection(id)`, `settings(page)`, `draft`, `workspace`). `WorkspaceModel` answers `commands(for:)`, `availability(of:target:)` (with the reason in words), `choices(for:target:)`, and `run(_:target:argument:generation:)`. `run` checks the account generation, the target, and the availability again before it sends anything, and returns `completed`, `failed`, or `unknown`; a call that was sent and not answered is `unknown`, never done and never failed.
  - **Model and permission** are the composer pickers' own lists (`PickerMenus`) and the same `setThreadRuntime` call, so the palette cannot offer what a picker would not. An existing thread keeps its connection; "New thread with another runtime" prepares the new-thread draft.
  - **Find** (⌘K; the list's search button on the iPhone) searches thread titles (with the environment and connection at half weight), environments, connections, settings pages, and commands. Matching is local (`FuzzyMatch`): several terms, each exact, a prefix, a word start, inside, initials, or letters in order from a word start. Typed relevance leads; among equal matches threads keep attention order and archived ones come last. Empty input lists up to four threads that need the owner, three recent ones, New thread, and Commands. A query that finds fewer than three rows also offers "Use as message", which puts the text in the destination's draft only when that draft is empty and never sends.
  - **Commands** (⇧⌘P, or `>` or `/` as the first character in Find) lists the open thread's commands (or the new-thread draft's) and the workspace's. Backspace in the empty field returns to Find.
  - **Pages.** Tab on a thread shows its actions; a `choice` command lists its values with the current one marked and a line saying when the change applies; Rename turns the field into the title with its text selected. Escape and ⇧Tab go back one level, then close. Each level keeps its own text and selection. The selection is kept by the row's identity while the list changes under it, and the pointer selects a row only when the pointer itself moved.
  - **Outcomes.** A command that completes closes the palette and is announced to VoiceOver; the change on screen is the confirmation. "Requested" shows only when the answer takes longer than 150 ms. A failure or an unconfirmed outcome keeps the palette on the same page with the same text.
  - **Requests.** The palette opens the thread ("Review request"); approving and answering stay on the request card. Check again, Abandon turn, and Stop turn are the composer's own calls. Delete is not in the palette.
  - **Drafts and focus.** The palette never writes a draft except through "Use as message". Closing it asks for the cursor back in the open thread's composer or the new-thread draft (`composerFocusRequest`, `newThreadFocusRequest`); the Mac only, so the phone's keyboard does not rise.
  - **`/` in the composer** (`SlashCommands.swift`). Completions open only when a slash is typed as the first character of an empty draft and stay while the text is a single token. A pasted path, a slash further in, or a token no command answers to is a message. While completions show, the round control and Return pick the selected command, so a typed slash is never sent and never stops a turn; Escape closes the completions and nothing else. A thread offers `/model`, `/permissions`, `/pin`, `/archive`, `/unread`, `/new`; the new-thread draft offers `/environment`, `/model`, `/permissions`.
  - **Look and motion.** LLA tokens only. Rows are 32 pt with one 16 pt content edge; row symbols are in `ghost`. The card is 600 pt wide, 96 pt from the top, and only its bottom edge moves between pages. Open is 160 ms, close and page changes are shorter, the keyboard's highlight slides in 90 ms; Reduce Motion replaces all of it with an 80 ms fade.
  - **Not built.** Runtime commands (Claude Code's own slash commands and skills, Codex's review and compact) are not offered: Claude Code reports its commands in the `initialize` answer the adapter discards, and Codex has none to list, so both need a contract of their own. Transcript search, queueing, steering, and shell execution are not offered either.
  - **Tests.** `PaletteTests` (matching, the catalog, re-checking at dispatch, result order and duplicates, selection by identity, scopes, the page stack, failure keeping input, drafts, focus requests, a 3,000-thread filter that is inside 50 ms in a debug build run alone and is asserted at 100 ms so a loaded machine does not fail it, and the `/` rules). The snapshot suite renders the palette's pages and the completions in both appearances.
