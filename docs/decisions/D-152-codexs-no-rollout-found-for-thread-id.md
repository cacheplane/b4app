## 2026-11-02 (step-up by enrollment code, and two live-check fixes)

- **D-152 Codex's "no rollout found for thread id …" means the thread is already gone.** Amends D-138. Deleting threads at the live checks left four Codex deletes waiting for ever: codex-cli 0.166.0 answers `thread/delete` for a thread it keeps no rollout of with `-32600 no rollout found for thread id …`, which did not say "not found", so it was retried every hour. Codex listed none of those ids (383 threads, archived ones included), so there is nothing to delete. `CodexAdapter.saysAlreadyGone` accepts that message too; any other error is still retried.
- **A passkey sheet that cannot open says what to do.** `ASAuthorizationError.failed` (1004) from the sign-in, the confirmation, or the creation sheet is now `PasskeySheetFailed`, shown as "The passkey sheet couldn't open. If another passkey request is still on screen, close it, then try again." At the live checks a sign-in failed this way while a cancelled confirmation's request was still open in the system and read "Couldn't sign in. Try again."; the same code also covers an app not yet associated with the passkey domain, so the line names the cause the person can fix. A confirmation that fails so also offers the code (D-151).
