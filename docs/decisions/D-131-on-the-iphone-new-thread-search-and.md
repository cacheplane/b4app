## 2026-11-02 (iPhone thread list toolbar)

- **D-131 On the iPhone, New thread, Search and More move into the navigation bar; amends D-053.** The owner chose this after D-053 left the iPhone with the Mac's three sidebar rows, which took the top of the screen before the first thread. The Mac keeps its rows.
  - **New thread** is a compose button (`square.and.pencil`) at the right of the navigation bar, off while no project's Mac can take a thread, as before.
  - **More** is a filter button beside it (`line.3.horizontal.decrease.circle`, filled while a filter narrows the list) that opens the same menu: the project filter, Rename for a chosen project, and the connection filter.
  - **Search** is the system search field (`.searchable`), which iOS 26 places at the bottom of the screen. It narrows the list itself, by shown title in any case (an untitled thread matches "Untitled"), together with the filters. The list says "No matching threads." when nothing matches. It replaces the iPhone's Search sheet; the Mac keeps its ⌘K palette.
  - **The list has a large title:** "Threads", or the chosen project's name while the list is filtered to one. The profile button stays at the bottom.
