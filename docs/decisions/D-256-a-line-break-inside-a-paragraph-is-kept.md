## 2026-11-19 (line breaks inside a paragraph)

- **D-256 A line break inside a paragraph draws as a line break, whether or not the line ends in a hard break's marker. Amends D-252's deviations.** D-252 drew a soft line break as a space, as CommonMark has it, and noted that every newline had been kept before. On screen in the Local build from main (99bf5ec5), a Claude Code reply of the numbers 1 to 120, one per line, drew as four wrapped lines of numbers; the stored text still had its 120 lines. Replies set lines apart with nothing but a line break often: numbers, addresses, verse, short lists without markers, a log excerpt outside a fence.
  - **The rule.** `BlockState.paragraphText()` joins a paragraph's lines with a line break. A hard break's marker (two or more trailing spaces, or a backslash) is still dropped, so the backslash never draws; it no longer changes what is drawn. Blank lines still split paragraphs, and everything else in D-252 stands: a lazy line still continues a paragraph in a quote or item, and a header whose delimiter row never arrives is still one paragraph, each now with its line breaks.
  - **What it costs.** Prose a model wraps at a fixed column draws with those breaks instead of reflowing to the window. This is one more deliberate deviation from CommonMark, on the side the app was on before D-252.
  - **Tests.** `LeafBlockTests` (`paragraphsAreSplitByBlankLinesAndALineBreakInOneIsKept`, `linesSetApartByLineBreaksStayApart`, `aHardBreaksMarkerIsDroppedAndItsLineBreakKept`) and `MarkdownViewTests.aLineBreakInAParagraphIsALine` (the hosted view is as tall for `one\ntwo` as for a hard break); the first, second and fourth failed against the old join. Fifteen other expectations in `StreamingMarkdownTests` that spelled a joined paragraph with a space now spell it with the line break.
