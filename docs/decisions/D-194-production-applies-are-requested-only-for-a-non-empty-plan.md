## 2026-11-09 (hosted-hub operations: approval noise and the silent copy failure)

- **D-194 A production Terraform apply is requested only when a read-only plan shows changes, runbook edits do not trigger the infrastructure workflow, and a failed backup copy job alerts. Amends D-070 and D-071.** Two things surfaced in the first week of running the hubs. Every merge that touched `Infra/`, including runbook-only edits to `Infra/README.md`, ran `infra.yml` on `main`, applied test (no changes), and parked a production approval request in the `production` Environment; two such requests sat unanswered for days and would have applied nothing. And the first scheduled copy of production's backup to `us-west-2` failed (the region policy denied `rds:CopyDBSnapshot`) without any signal, because AWS Backup reports copy jobs as events, not metrics.
  - **Plan first, then the gate.** `infra.yml` gains a `Plan prod (main)` job that runs after the test apply with the read-only plan role and `terraform plan -detailed-exitcode`; the gated `Apply prod` job runs only when that plan reports changes, re-plans with the infra role, and applies. The decision is made before the Environment gate, so the owner is asked only for real changes. The gated job plans again rather than applying an uploaded plan file, because the repository is public and a saved plan carries variable values (the alarm email is marked sensitive).
  - **Paths.** `Infra/README.md` is excluded from the workflow's path filters for pull requests and pushes. Everything else under `Infra/` still plans on pull requests and applies on `main`.
  - **Copy failures alert.** The hub module adds an EventBridge rule for `aws.backup` `Copy Job State Change` events in state `FAILED`, targeting the alerts topic, whose policy now allows both event rules to publish. The rule exists in every environment and never matches where there is no copy region.
  - **Why not fewer applies altogether.** Applying on every merge to `main` stays (D-070): it keeps the test account continuously converged, and the skipped production job costs nothing when the plan is empty.
