## 2026-11-06 (archive changes reach the background widget)

- **D-191 Archive and unarchive updates request a silent mirror refresh on the user's other phones.** Amends D-121 and D-126. Physical testing on production TestFlight 2611061754 showed that archiving completed test threads on the Mac left them in the background widget; they eventually cleared after foreground sync. The transaction now detects successfully applied updates of `threads.archived`, in either direction, and selects one refresh per eligible other phone per batch. Duplicate uploads, losing/refused/skipped changes and unrelated column updates cause none. Eligibility reuses the user's organisation, session, revocation and push-token checks, excludes the uploader, and omits each recipient already receiving an alert or withdrawal in that batch. Quiet threads need no notification ledger entry.
  - The refresh is sent after commit through the existing sender and retry/dead-token path: `{"aps":{"content-available":1},"refresh":true}`, APNs background type, priority 5, 15-minute lifetime and constant `mirror-refresh` collapse id. It contains no title, thread id, navigation, withdrawal key, alert, sound or badge. The spool adds only its normal target bundle. Recipient debug output redacts the token.
  - The iOS delegate already refreshes on every background push, so it reuses the account-owned end-of-feed catch-up, widget reload and notification/badge reconciliation before parking the mirror. No migration, HTTP route, entitlement or minimum OS change. Delivery and widget rendering remain controlled by iOS; requesting a wake does not guarantee immediate rendering.
  - Tests reproduce the missing quiet-thread route delivery before implementation and cover the transaction, deduplication, eligibility, overlap with existing pushes, fake HTTP/2 APNs headers, spool and shared Rust/Swift payload contract. The widget's file-backed read-only test verifies archive filtering. Release and physical retest evidence belongs in `docs/verification/2026-11-06-archive-background-wake.md`.
