- **D-062 The Mac ships only as a notarized Developer ID download and a Homebrew cask; there is no Mac App Store or TestFlight-for-Mac build.** Amends D-051. Both channels require App Sandbox on every executable. A sandboxed process can execute nothing outside its bundle and a few system locations; no file grant adds execute permission, and Apple DTS says so. Children inherit the sandbox with `HOME` moved into the container, so the user's `codex`, `claude`, and `node` cannot run, and their `~/.codex` and `~/.claude` logins are invisible. App Review rejected a home-folder exception for an agent-CLI app in April 2026. PostgreSQL needs System V IPC, which the sandbox denies, and a sandboxed app cannot write the LaunchAgent. T3 Code, ChatGPT/Codex, Claude desktop, Zed, Warp, and Conductor all ship outside the store unsandboxed; Xcode runs agents from the store only because Apple exempts it. Bundling our own agents was rejected: they could not run the user's toolchains, they would need a second login, every model update would wait on review, and Claude Code's terms forbid modifying the binary, which Apple's re-signing may count as. The iPhone app ships through the App Store and TestFlight as D-051 set up. The owner's words: "macOS is installed like codex and claude - download or homebrew."
  - *Built:* `Scripts/release-mac.sh` and the cask `Packaging/homebrew/agent-workspace.rb` (`docs/release.md`); nothing has been released, and the tap is the owner's to create.
