## 2026-10-31 (agent)

- **D-042 The background coordinator runs from a per-user LaunchAgent plist the app writes and bootstraps, not from an `SMAppService` bundle agent.** The managed agent pins a lightweight code requirement to the registered program; with an ad hoc signature that is the binary's own hash, so every rebuild left the job loaded but unspawnable ("spawn scheduled", exit 78 EX_CONFIG, retried every ten seconds) while the previous coordinator kept serving from its deleted file, and neither `register` again nor unregister-and-register refreshed it. The same binary bootstrapped under a plain label ran at once. The app now writes `~/Library/LaunchAgents/com.cacheplane.b4app.coordinator.plist` with the bundled coordinator's absolute path, rewrites and re-bootstraps it when the path changes or launchd reports a spawn failure, unregisters a leftover managed agent once, and removes the plist on "Remove Background Agent" or `--remove-agent`; `coordinator status|restart|plist` keep the label. The bundle still carries its `Contents/Library/LaunchAgents` plist for a future Developer ID build, where the managed agent's requirement would be stable. Supersedes the hosting part of D-038.
