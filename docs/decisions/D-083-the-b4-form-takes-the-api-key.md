## 2026-11-02 (settings: connections, usage, B4 projects)

- **D-083 The B4 form takes the API key itself, and Edit keeps a connection's identity (revises D-022's "the GUI form collects the reference, never the value").** The owner: "it's fine to take the API key and securely store it." The form sends the key with `credential.add` over the 0600 socket, the same path as the CLI, keeps only the returned `secret:` reference, and clears the field when the save returns, whether it worked or not. `connection.update` changes the label, and for B4 the credential (replace or remove); the server and the agent stay, since another endpoint or route is another connection (spec 5.2, D-032). A replaced key is a new reference used in place, so threads keep their scope (the B4 scope is the origin); the cached adapter is dropped so the next turn uses it, and the old secret is deleted once no connection references it. Codex and Claude edit their name only. Removing a connection or a project is not built: what becomes of its threads needs its own decision.
