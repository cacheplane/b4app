## 2026-10-31 (M8a)

- **D-044 The hub owns users, organisations, devices, and credentials; no identity provider is bundled.** M8a enrolls a device with a one-time code: `b4hub enroll --user` mints eight characters from `BCDFGHJKLMNPQRSTVWXZ23456789` (no vowels, no `Y`, no `0` or `1`), valid ten minutes and single use, which a client redeems for a device token (32 random bytes, base64url). The hub stores only the token's SHA-256 and shows the token once. Revoking a device deletes its token rows and sets `devices.revoked_at`; the history it uploaded stays. The sign-in flows (PKCE for the apps, the device grant for the CLI, rotating refresh-token families, self-registration, SSO brokering) are M8d and extend these tables instead of replacing them. The enrollment code is read from the terminal with `readSecret`, never from an argument, and the phone clears its field once the request returns.
