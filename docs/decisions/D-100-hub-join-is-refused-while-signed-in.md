## 2026-11-02 (sign-in build)

- **D-100 `hub join` is refused while signed in, and `hub leave` revokes this Mac, then signs out.** `AccountManager.join`, `leave`. Signed out, `hub join` enrolls with the code, asks `/v1/me` for the user, and signs in exactly as a sign-in does: the operator path for a hub with sign-up closed. Signed in, it is refused with `protocol_invalid` before anything reaches the hub ("This Mac is signed in to <org>. Log out first, then join a hub with an enrollment code."), because the join would bind one account's database to another hub user and race a sign-out. `hub leave` runs outside the scope gate, revokes the device, forgets its token and link, and signs out even when the leave fails part-way (then rethrows); the app offers it as "Remove this Mac from your account" on Remote access. Since leaving signs out, `database.restore` is now possible only for an account that has joined no hub ("Restore into an account that has not joined a hub.").
