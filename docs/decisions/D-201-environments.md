## 2026-11-10 (environments)

- **D-201 A project is an environment (amends D-048 and D-084).** What D-048 called a project, a named set of folders on one Mac that threads work in, is an environment, in the interface and in every store and wire contract. "B4 project" is a different feature, the folder of a B4 app a managed server runs (D-084), and keeps its name everywhere.
  - **Names.** Tables `environments` and `environmentFolders`, column `environmentId`, router methods `environment.list|create|update|rename|delete`, event `environment.changed`, error code `environment_missing`, and the matching JSON keys. The Swift type is `WorkEnvironment` (and `EnvironmentFolder`, `EnvironmentService`, and the rest) because SwiftUI already has `Environment`. User-facing copy says "Environment"; a thread with no folder says "No folder". `Server.projectPath`, the CLI's `projectDir`, `B4ProjectsView`, and Claude Code's `projectsDirectory` are unchanged.
  - **No aliases.** Old names are replaced, not kept beside the new ones (no dual decoding, no old method names). One forward migration per store (hub `0018`, coordinator `0011`, the phone's mirror schema version 7) renames the tables, columns, indexes and triggers and rewrites the old names stored as data in the change logs and clocks, so unpushed changes and per-column clocks carry over.
  - **Rollout.** Deploy the hub (migration 0018) and install the Mac and phone builds together, in a quiet moment. The hub does not refuse a change that names an old table: it records it and skips it. An environment edit pushed by a not-yet-upgraded app after the hub is deployed is therefore lost, not retried. With two hub tasks, the old task errors on the renamed tables until it is replaced.
  - **Accepted one-time resets.** The per-device new-thread memory (`newThread.memory` in `LocalPreferences`: last place, folder, runtime, and any unsent first-message draft) and the Mac's collapsed-sections state (`@SceneStorage` key `collapsedEnvironments`) start fresh, because their stored keys were renamed. Export archives made before the rename (tables named `projects`) no longer restore.
